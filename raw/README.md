# raw/ - your sources (you own this)

Drop source material here: exported notes, articles, PDFs, meeting transcripts, saved
threads, anything you want the librarian to read. This folder is **immutable to the AI** -
it reads from `raw/`, but never edits or reorganizes it.

- Put new material directly in `raw/`.
- After the AI ingests a file, it moves it to `raw/processed/` so you can see what's been
  absorbed into the wiki.
- Keep the original source. The wiki cites back to it; it is the ground truth.

**Never paste live secrets here** (tokens, passwords, one-time codes). See the Secrets rule
in `CLAUDE.md`.
