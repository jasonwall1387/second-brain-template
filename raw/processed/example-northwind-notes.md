# Example source note - Northwind Consulting (illustrative)

> This is a sample raw source so the example wiki pages have something real to cite.
> Delete it along with the `example-` wiki pages once your own content lands.

Northwind Consulting is a two-person independent consultancy (founder + one contractor)
doing fractional operations work for small e-commerce brands. Founded 2024. Based in Austin.

Current clients: Acme Corp (biggest, ~40% of revenue). Engagement is a website refresh plus
ongoing ops support.

Positioning we keep coming back to: we win when we say "fractional ops for DTC brands under
$5M", not "consulting". The niche closes deals; the generic pitch stalls.

Decision, mid-January 2026: standardized the internal knowledge base on Obsidian + Claude
Code (the LLM-wiki pattern) instead of Notion, because we wanted plain-file ownership and an
AI that maintains the wiki for us.

Tools/accounts: domain + email on Fastmail, site on Shopify, invoicing through Stripe,
project tracking in Todoist. Card on file is the business Amex.
